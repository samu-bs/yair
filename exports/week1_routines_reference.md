## How to build these in Hevy (3 routines, ~10 min)

1. Open Hevy → bottom nav → **Routines**.
2. Tap **+ New Routine** (top right).
3. Title: `Push A` (or `Pull B`, `Legs C`).
4. Tap **+ Add Exercise** → search by name (use the **Hevy name** column above).
5. After adding an exercise, tap it → set **Sets** count → set per-set **Reps** and **Weight** as above. For rest times: long-press an exercise → **Rest Time** → set 90s.
6. Save the routine.
7. Repeat for the other two.

To use during a workout: Routines tab → tap routine → **Start Routine**. Hevy will guide you set-by-set, autofill weights from last time, and let you adjust if you go heavier.

## CSV import (alternative path)

The file `week1_hevy_routines.csv` is in Strong-app format. To try it:

1. Hevy → **Profile** → **Settings** → **Export & Import Data** → **Import Data** → **Import Strong CSV**.
2. Select `week1_hevy_routines.csv`.
3. If it imports → you'll see 3 workouts dated 11/5/2026 in your history.
4. Open each workout → **⋯ menu** → **Save as Routine** → name it → save.
5. After saving all three, you can delete the dummy history entries.

If the import fails or names don't map cleanly, fall back to manual entry above.
