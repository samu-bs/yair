# site — תוכנית האימונים של יוסי

אתר סטטי המכיל את התוכנית השבועית של יוסי. נבנה ע"י יאיר (המאמן הראשי) על בסיס נתוני יוסי וייעוץ פנימי עם הצוות (ד"ר אסף, יואב, עמית, דניאל).

## מבנה

```
site/
├── index.html          # דף נחיתה — רשימת שבועות, יעדים, צוות
├── weeks/
│   ├── week1.html      # שבוע 1: 12–18 במאי 2026
│   ├── week2.html      # יתווסף בצ'ק-אין הבא
│   └── ...
├── .gitignore
└── README.md
```

## איך זה עובד

- כל שבוע = קובץ HTML יחיד עם CSS פנימי. אין תלויות חיצוניות — פותח מכל דפדפן.
- מותאם לנייד (RTL, hamburger בנייד, ניווט מהיר).
- קישורי הדגמה לתרגילים פותחים חיפוש ביוטיוב — מחזיק לעד גם אם סרטונים בודדים נמחקים.

## עדכון

הצ'ק-אין השבועי (כל יום ראשון 17:00) מייצר את `weekN.html` הבא. רץ אוטומטית כמשימה מתוזמנת.

## הוספה לשרת

הקבצים סטטיים — אפשר לשרת מכל שרת HTTP (GitHub Pages, Netlify, Nginx, וכו'). שורש האתר = תיקיית `site/`.
